# Portfolio Website

A modern, multi-page portfolio website with organized file structure.

## 📁 Project Structure

```
portfolio/
├── index.html              # Root file (redirects to home page)
├── Akshay.jpeg            # Profile image
├── home/                  # Home page
│   ├── home.html
│   ├── home.css
│   └── home.js
├── about/                 # About page
│   ├── about.html
│   ├── about.css
│   └── about.js
├── skills/                # Skills page
│   ├── skills.html
│   ├── skills.css
│   └── skills.js
├── certifications/        # Certifications page
│   ├── certifications.html
│   ├── certifications.css
│   └── certifications.js
├── projects/              # Projects page
│   ├── projects.html
│   ├── projects.css
│   └── projects.js
└── contact/               # Contact page
    ├── contact.html
    ├── contact.css
    └── contact.js
```

## 🚀 Getting Started

1. Open `index.html` in your browser, or
2. Navigate directly to `home/home.html`

## 📄 Pages

- **Home** - Hero section with introduction and statistics
- **About** - Professional summary and personal background
- **Skills** - Technical skills organized by category
- **Certifications** - Professional certifications
- **Projects** - Featured project showcase
- **Contact** - Contact form and information

## 🎨 Features

- Responsive design for all devices
- Smooth animations and transitions
- Mobile-friendly navigation
- Interactive elements
- Clean, organized code structure

## 🛠️ Customization

1. Update personal information in each HTML file
2. Replace placeholder images with your own
3. Modify colors in CSS files (check `:root` variables)
4. Add your projects, skills, and certifications

## 📱 Responsive

The website is fully responsive and works on:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)
